Avances para este semestre

Avance del proyecto Loock-Home

Durante el quinto semestre se ha avanzado significativamente en el desarrollo del proyecto Loock-Home, enfocándonos principalmente en la integración de los componentes electrónicos, la programación del microcontrolador ESP32 y la comunicación entre el sistema físico y una plataforma web. En esta etapa buscamos que la maqueta no solamente permita demostrar el funcionamiento de los sensores y actuadores, sino que también pueda transmitir información y recibir instrucciones desde una interfaz digital. De esta manera, continuamos fortaleciendo la propuesta de domótica, orientada a mejorar la seguridad, el monitoreo y el control de diferentes funciones del hogar.

Desarrollo e implementación del sistema

Durante esta etapa se ha trabajado en la integración de los diferentes elementos que conforman el sistema Loock-Home, utilizando una ESP32 como unidad principal de procesamiento. Se han realizado pruebas individuales y de integración con los sensores, módulos de relé y dispositivos de salida, buscando establecer una comunicación funcional entre los componentes físicos y la plataforma de supervisión.


Implementación de hardware

Para la implementación física se está utilizando una tarjeta ESP32 DevKit V1, encargada de recibir las señales de los sensores y controlar los actuadores del sistema. Se incorporaron sensores infrarrojos (IR) para la detección de presencia u objetos en diferentes zonas, un sensor DHT11 para medir la temperatura y humedad del ambiente, y un sensor MQ-6 para la detección de gases. También se implementaron módulos de relé para controlar las salidas eléctricas correspondientes a la iluminación, ventilación y extracción. Cada componente se ha sometido a pruebas de conexión y funcionamiento para verificar su correcta integración.


Desarrollo de software

En la parte de programación se desarrolló un código para la ESP32 utilizando el entorno Arduino IDE y el lenguaje C++. Se configuraron las entradas de los sensores y las salidas destinadas al control de los relés, estableciendo condiciones automáticas de funcionamiento. Los sensores infrarrojos permiten controlar individualmente tres puntos de iluminación, mientras que el sensor DHT11 permite activar un ventilador cuando la temperatura alcanza los 30 °C y desactivarlo cuando desciende a 28 °C. Por otra parte, el sensor MQ-6 se utiliza para detectar la presencia de gases y activar el sistema de extracción mediante un relé.


Comunicación y monitoreo

Uno de los avances más importantes de este semestre ha sido la implementación de la comunicación Wi-Fi entre la ESP32 y un servidor local desarrollado mediante XAMPP. Para ello se utiliza el protocolo HTTP, mediante solicitudes POST que permiten enviar información en formato JSON desde el microcontrolador hacia el servidor. También se ha trabajado con PHP para recibir y procesar los datos, junto con MariaDB como sistema de gestión de bases de datos. Adicionalmente, se está desarrollando una interfaz web que permitirá visualizar los estados de los sensores y realizar el control de los actuadores desde un dispositivo conectado a la misma red.

Meta del semestre

La meta principal del quinto semestre es lograr una mayor integración entre el hardware y el software del proyecto Loock-Home, permitiendo que los sensores y actuadores trabajen de manera coordinada y que la información recopilada por la ESP32 pueda visualizarse desde una plataforma web. Se busca obtener un prototipo funcional que demuestre la automatización de la iluminación, el control de la temperatura, la detección de gases y la comunicación entre el sistema físico y el usuario, sentando las bases para continuar con el desarrollo del proyecto en los siguientes semestres.


Nueva versión de maqueta

1Desarrollo de la maqueta

Durante este semestre se ha continuado trabajando en la evolución física de la maqueta de Loock-Home, enfocándonos en la organización de los componentes electrónicos, la distribución de los sensores y actuadores y la implementación de los circuitos de control. Se busca mejorar la presentación y funcionalidad del prototipo, integrando los diferentes sistemas de automatización en una estructura que represente las condiciones de una vivienda real. Además, se ha trabajado en el diseño de una tarjeta electrónica PCB para organizar las conexiones y facilitar el montaje de los componentes.


2Integración de componentes

La integración de los componentes se realiza mediante la ESP32 DevKit V1, que funciona como unidad central de control. En esta versión se busca conectar los sensores infrarrojos, el DHT11 y el MQ-6 con los respectivos módulos de relé. Cada entrada y salida se encuentra organizada de acuerdo con la función que cumple dentro del sistema. También se realizan pruebas en protoboard y sobre el diseño de la PCB para comprobar las conexiones, verificar las señales recibidas y garantizar el funcionamiento adecuado de los actuadores.
